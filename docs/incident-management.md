# Incident Management & Root Cause Analysis (RCA) Guide

## Severity Classification
- **P1_CRITICAL**: Campus-wide outage, physical safety hazard, critical data breach.
- **P2_HIGH**: Core service failure (Attendance down, Examination portal inaccessible).
- **P3_MEDIUM**: Partial service disruption or isolated system error.
- **P4_LOW**: Minor cosmetic or non-blocking inconvenience.

## Post-Mortem & Corrective Action Tracking
Every resolved incident requires:
- **Root Cause Analysis (RCA)**: Detailed technical description of the underlying failure cause.
- **Corrective Actions**: Immediate remedies applied to recover service.
- **Preventive Actions**: Architectural, infrastructural, or procedural safeguards implemented to ensure non-recurrence.
